## 使用できる役職
### 村陣営
- 村人<br>
なんの能力も持っていないただの人。
能力を持っていないからこそ人狼に襲撃される事を恐れずに討論する事ができる。
しかし、自ら村人であると明かすのは役職持ちの潜伏枠を狭めることになるため、悪手である。
- 占い師<br>
毎夜一人、「人狼である」か「人狼でない」か占う事ができる。
- 霊媒師<br>
毎夜処刑された人、突然死した人が「人狼である」か「人狼でない」か見る事ができる。
- 騎士<br>
毎夜一人、人狼の襲撃から護る事ができる。
ただし自分自身を護ることはできない。
### 人狼陣営
- 人狼<br>
毎夜一人、襲撃する事ができる。
仲間の人狼がいる場合、誰か知っており、夜の間に話し合う事ができる。
- 狂人<br>
人狼に味方する人。
ただし誰が人狼かは知らない。
占い結果や霊媒結果は「人狼でない」と表記される。
### 第三陣営
- てるてる坊主<br>
自分が処刑されると勝利する。襲撃などの理由で死亡した場合は勝利とならない。
